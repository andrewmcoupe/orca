# Support

Use GitHub issues for reproducible bugs and well-scoped feature requests.

Before opening an issue:

- Check existing issues and pull requests.
- Confirm you are using the latest available release or a recent commit on `main`.
- Collect the Orca version, operating system, architecture, and relevant logs.

For general usage questions, open a question issue. For vulnerabilities, follow [SECURITY.md](SECURITY.md).
