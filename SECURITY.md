# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Orca.

## Reporting a Vulnerability

Please do not create a public GitHub issue for security vulnerabilities.

Report vulnerabilities through GitHub Security Advisories for this repository:

https://github.com/andrewmcoupe/orca/security/advisories/new

Include as much detail as you can:

- Affected version or commit SHA
- Operating system and architecture
- Steps to reproduce
- Impact and affected data or capabilities
- Any suggested remediation

## Response Expectations

The maintainers will aim to acknowledge valid reports within 7 days. Fix timing depends on severity, complexity, and release risk.

## Scope

Relevant vulnerabilities may include unsafe command execution, unintended file access, updater or signing issues, credential leakage, dependency vulnerabilities with a practical exploit path, or data corruption that can be triggered by untrusted input.
